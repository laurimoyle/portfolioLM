# Lauri Moyle portfolio

Edit artwork from a phone or laptop at https://app.pagescms.org by signing in with GitHub and choosing this repository.

The contact form uses the free Resend Vercel integration. Set RESEND_API_KEY, CONTACT_TO=Lauri@claimworth.art, and CONTACT_FROM=Portfolio <contact@send.claimworth.art>. Verify send.claimworth.art in Resend; this does not replace Google Workspace receiving records.
